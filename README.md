# Alguerisme

Alguerisme is a linguistic and digital project dedicated to the
preservation and revitalization of the Alguerés language, a variant
of Catalan spoken in Alghero (L’Alguer), Sardinia, Italy.

At its core, Alguerisme aims to develop lexical tools to support
the use and learning of the Alguerés language. The project aims to create
utilities for collecting, processing, and exploring Alguerés lexical data,
as well as foundational tools for embedding-based word search and translation.

By combining language, technology, and cultural heritage, Alguerisme
seeks to strengthen the presence of the Alguerés language in digital spaces
and contribute to its long-term sustainability.
